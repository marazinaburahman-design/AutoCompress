# AutoCompress product website

React + Vite marketing site for the AutoCompress Windows desktop app.

## Local development

```bash
npm install
npm run dev
npm run build
```

## Deployment

Deploy this repository to Vercel with the project root directory set to `website`. Build command: `npm run build`. Output directory: `dist`.

The download CTA currently links to the GitHub Releases page for v0.1.0. Attach the Windows installer asset to that release before announcing direct downloads.

All product claims are based on the current desktop application's README and supported-format documentation. Do not advertise unimplemented conversions or claim that the installer is signed.
